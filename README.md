## 📚 Course Overview

This repository contains lecture slides and supplementary materials for **Object-Oriented Programming**, a 5 ECTS credit course introducing OOP concepts using Java as the illustration language.

### Learning Objectives

Upon completion, students will be able to:

- ✅ Compile and run Java applications
- ✅ Understand core OOP concepts (encapsulation, abstraction, inheritance, polymorphism, reusability)
- ✅ Design and develop programs using object-oriented principles
- ✅ Create Java applets for browser environments
- ✅ Understand Java networking fundamentals

## 🗂️ Course Contents

| Module | Topic |
|--------|-------|
| **1** | Introduction to Java |
| **2** | Revision of Basic Programming Constructs (Variables, Data Types, Operators, Control Structures) |
| **3** | Arrays & Methods |
| **4** | Introduction to Classes and Objects |
| **5** | Static and Final Members |
| **6** | OOP Concepts: Encapsulation, Abstraction, Inheritance, Polymorphism |
| **7** | Interfaces and Abstract Classes |
| **8** | Sound Class Design Principles |
| **9** | Packages |
| **10** | GUI Programming with Swing |
| **11** | Exception Handling |
| **12** | Java Generics |
| **13** | I/O and Parsing |
| **14** | Java Networking |
| **15** | Web Development (HTML & JSP) |
| **16** | Database Programming with JDBC |
